# Social Network

## About the Project

Social Network is a web application designed to connect users and provide a platform for social interaction. Users can create accounts, manage their profiles, share content, and interact with other members of the community.

The project focuses on building a user-friendly social networking experience while applying modern web development practices.

## Features

- User registration and authentication
- User profile management
- Create and share posts
- Interact with other users
- Follow and connect with users
- Responsive user interface

## Technologies Used

- **Frontend:** Angular
- **Backend:** Java, Spring Boot
- **Database:** PostgreSQL
- **Authentication:** JWT
- **Version Control:** Git and GitHub

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Java
- Node.js and npm
- Angular CLI
- PostgreSQL
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/khalidrika/social-network.git
   ```

2. Navigate to the project directory:

   ```bash
   cd social-network
   ```

3. Configure the database connection.

4. Start the backend application.

5. Install frontend dependencies and start the Angular application.

## Project Goal

The goal of this project is to develop a functional social networking platform while improving skills in full-stack development, REST APIs, database management, and application security.
